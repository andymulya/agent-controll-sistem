# agent-controll-sistem

Control Center pribadi Andy: dashboard statis (Bahasa Indonesia, mobile-first)
untuk memantau status LLM, agen, dan perintah kerja. Deploy via Vercel.
Akses dibatasi hanya untuk email Andy (login Google).

- `index.html` — dashboard lengkap (satu file, tanpa backend).
- Hanya menampilkan layanan gratis. Tidak ada daftar berbayar.
